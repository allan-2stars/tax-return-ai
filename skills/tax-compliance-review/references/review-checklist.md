# Compliance Review Checklist

For every candidate deduction, confirm:

- There is evidence.
- Amount is present.
- Date is present.
- Supplier/source is present where applicable.
- Work-related nexus is explained.
- Private use is apportioned where applicable.
- Reimbursement status is known.
- Duplicate status is resolved.
- User confirmation is present for medium/high-risk items.

If any point is unresolved, the item should not be treated as export-ready without review notes.
